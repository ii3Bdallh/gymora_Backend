## 1. Global Conventions

### 1.1 Response envelope
Every action returns `Result<T>`:

| Property | Type | Notes |
|---|---|---|
| `IsSuccess` | `bool` | |
| `Error` | `{ Code, Message }` | null on success |
| `Data` | `T` | payload |

### 1.2 Pagination
- Request: `PaginatedSearchReq` (sent in the **request body** even on `POST`):
  - `PageSize` (default 10, max 50), `PageNumber` (default 1), `SearchTerm` (max 100), `OrderBy` (default "Id"), `OrderDirection` (default "asc"), `IsActive` (default true), `Filters?` (`FilterRequest`).
- Response: `PaginatedRes<T>`: `TotalCount`, `PageSize`, `PageNumber`, `TotalPages`, `HasPrevious`, `HasNext`, `Items`.

### 1.3 Authorization model
| Attribute | Meaning |
|---|---|
| `[AllowAnonymous]` | No auth required. |
| `[Authorize]` | Any authenticated user (platform-level). |
| `[Authorize(Roles = "...")]` | Platform role required (`SuperAdmin` / `User`; `AppRole.SuperAdmin`, `nameof(RoleType.SuperAdmin)` = `"SuperAdmin"`). |
| `[GymAuthorize(params roles)]` | Custom filter (`Api/Filters/GymAuthorizeAttribute.cs`): requires an authenticated user; **SuperAdmin bypasses all gym checks**; requires `CurrentGymId` (from JWT) — otherwise `403 Forbid`; if roles are supplied, `GymRole` must match one of them (Owner always passes). No roles = any gym role. |

**Platform roles:** `SuperAdmin`, `User` (see `AppRole`). **Gym roles:** `Owner`, `Manager`, `Coach`, `Receptionist`, `Cleaner`, `Other`, `Member` (see `GymRoleString`).

### 1.4 GymId behavior (GymId resolution & scoping)
GymId is **never supplied by the client for gym-scoped resources**. It comes from the JWT access token:

- `CurrentUserMiddleware` reads `CurrentGymId` from the `CurrentGymId` claim and populates `CurrentUser.CurrentGymId`.
- The token's `CurrentGymId` is the "active workspace" selected by the user (set/updated on login and via `POST api/Auth/switch` — `Infrastructure/Repo/AuthRepo.cs`).
- **Reads** (`GetPageAsync` / `GetByIdAsync` via `BaseGymRepo.ApplyExtraFilters`): rows are automatically filtered to `GymId == CurrentGymId`. SuperAdmin sees all gyms; users without a `CurrentGymId` see nothing (`query.Where(_ => false)`).
- **Writes** (`BaseGymService.BeforeAddAsync/BeforeUpdateAsync`): `dto.GymId` is `[BindNever]` (cannot be bound from request). The service stamps `dto.GymId = CurrentGymId` and throws `ForbiddenException` when there is no current gym. `BeforeDeleteAsync` verifies the entity belongs to the current gym.
- **Route/query gymId endpoints** (financial reports, attendance dashboard, leave-gym): the service validates `gymId == CurrentGymId` for non-SuperAdmins.
- **Global (non-gym) resources** (SubscriptionPlans, Coupons, PaymentRequests, OwnerSubscriptions, UserWorkoutBlocks, Users, platform-level Gym CRUD): no gym scoping — access is governed by platform roles only.

**Auditable fields:** `CreatedById` / `CreatedByPersonId` come from the authenticated user context; they are not client-controlled.

### 1.5 Binding
- `[FromBody]` where stated; otherwise route/query.
- `[FromForm]` for file-upload DTOs (`GymCDTO`, `GymUDTO`, `PaymentRequestCDTO`).
